# مصروفي — مثال تعليمي لبناء APK

قالب ويب عربي بسيط يوضح تحويل HTML وJavaScript إلى تطبيق Android باستخدام Capacitor وGitHub Actions، دون تثبيت Android Studio.

## ما يعمل الآن
- تسجيل مصروف بوصف ومبلغ واحد، مع دعم الأرقام العربية والكسور حتى خانتين.
- حفظ المصروفات وحالة مهمتين تجريبيتين محليًا في `localStorage` واسترجاعها بعد إعادة التحميل.
- حساب الإجمالي والمتبقي من ميزانية تجريبية ثابتة قدرها 8000 جنيه وإظهار التجاوز.
- فلترة بسيطة للمشتريات والفواتير بكلمات مفتاحية، **وليست نموذج AI**.
- جميع ملفات العرض ضمن `www`؛ لا يحتاج APK اتصالًا لعرض الواجهة أو تسجيل المصروفات.

مثال: `قهوة ٦٥٫٥٠ جنيه` أو `فاتورة 1,200 جنيه`. إذا احتوى المدخل أكثر من رقم أو مبلغًا غير صحيح، تظهر رسالة ولا يتم مسح المدخل.

## حدود المثال
هذا ليس تطبيقًا ماليًا للإنتاج: لا مزامنة سحابية أو ذكاء اصطناعي أو تسجيل صوتي أو حسابات مستخدمين أو تحليلات. الأزرار غير المنفذة معطلة بوضوح. الأسماء والمهام والميزانية عناصر تعليمية. حفظ البيانات محلي وليس نسخة احتياطية أو تخزينًا مشفرًا؛ حذف التطبيق/مسح بياناته قد يمسح السجل. لا تدخل معلومات مالية حساسة. لا تستخدم هذا المثال كسجل محاسبي.

حُوّلت الخطوط والأيقونات الخارجية إلى خطوط النظام ورموز محلية حتى يعمل أول تشغيل دون إنترنت؛ لذلك قد تختلف هيئة الرموز بين الأجهزة. تشغيل نسخة الويب لأول مرة يحتاج تحميل ملفاتها، ولا توجد Service Worker لتثبيت نسخة PWA أوفلاين؛ ضمان تضمين الملفات هنا خاص بالـAPK.

## التشغيل والاختبار
```sh
npm ci
npm test
npm run build:css
```
اعرض مجلد `www` باستخدام خادم محلي بسيط مثل `python -m http.server 8000 --directory www`، ثم افتح `http://localhost:8000`.

الكود الرئيسي: `www/model.js` لتحليل المبالغ والتحقق، و`www/app.js` للحفظ والعرض. التصميم في `www/index.html` و`tailwind.config.js`. عند تعديل CSS شغّل `npm run build:css` واحفظ الناتج `www/styles.css`.

## إنشاء APK
عدّل اسم ومعرف التطبيق في `capacitor.config.json` ثم شغّل Workflow **Build Android APK** من GitHub Actions. الناتج **Debug APK** للتجربة وليس إصدار متجر. البناء يحتاج الإنترنت، أما تشغيل ملفات التطبيق المضمّنة فلا يحتاجه. لا تَعِد بمدة بناء محددة: تختلف حسب GitHub Actions والشبكة.

بعد البناء اختبر على هاتف فعلي: أضف مصروفًا، أغلق التطبيق بالكامل ثم افتحه، ثم كرر مع وضع الطيران من أول تشغيل. اختبارات المستودع تتحقق من منطق البيانات وبنية DOM، لكنها لا تغني عن اختبار Android فعلي.
